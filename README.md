# Sales Analysis Dashboard using Excel

## Project Overview
This project analyzes sales data using Microsoft Excel and presents key insights through a dashboard.

## Key Performance Indicators (KPIs)
- Total Sales
- Total Profit
- Total Orders
- Total Quantity

## Dashboard Visualizations
- Monthly Sales Trend
- Sales by Region
- Top Products by Sales
- Sales by Category

## Tools and Skills
- Microsoft Excel
- PivotTables and PivotCharts
- Data Analysis
- Data Visualization
- KPI Reporting

## Project Outcome
Created a dashboard to analyze sales performance, identify top-selling products, compare regional sales, and understand monthly sales trends.
